📚 Software Design Lab 1 – Personal Portfolio using Semantic HTML
📖 Project Overview

This lab was completed as part of my Software Design course at the University of the Witwatersrand.

The objective of this lab was to introduce the fundamentals of web development using HTML5 while emphasizing the importance of semantic HTML. The task involved creating a simple multi-page personal portfolio website that demonstrates the correct structure of a webpage using semantic elements.

The portfolio includes a homepage, an About Me page, a navigation menu, and sections describing my background and future software development projects.

🎯 Objectives

The aim of this lab was to:

Understand the basic structure of an HTML document.
Learn how to create multiple web pages.
Use semantic HTML elements to improve webpage structure and readability.
Create navigation links between web pages.
Build a simple personal portfolio webpage.

📚 What I Learned

Completing this lab strengthened my understanding of:

Creating HTML documents
Structuring webpages using semantic HTML elements
Building navigation menus
Linking multiple web pages together
Organizing webpage content logically
The importance of accessibility and readable webpage structure
This lab provided my first practical experience in developing a structured webpage using semantic HTML. It reinforced the importance of organizing content clearly and separating different sections of a webpage using appropriate HTML elements.

Although the project is simple, it established the foundation for future web development projects involving CSS, JavaScript, responsive design, and more advanced front-end development techniques.
